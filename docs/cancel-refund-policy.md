# 취소·환불 정책

[← README](../README.md) · [서비스 기획](service-plan.md) · [핵심 기능](core-features.md)

> 의뢰·제안이 중간에 취소될 때 예치금을 어떻게 돌려주고, 학생에게 얼마를 정산하는지 정리한 문서

## 기본 원칙

- **초안 제출 전까지만 취소할 수 있다.** 결과물을 받은 뒤 싸게 끝내는 편법을 막기 위해서다.
- 정산 기준은 진행률(%)이 아니라 **단계**로 정한다. 단계는 초안 제출 여부로 딱 나뉘어 다툼이 적다.
- 수정은 금액이 걸린 단계가 아니라 **권리**로만 둔다. 횟수는 사장님이 의뢰를 처음 등록할 때만 정할 수 있고(최소 1회 · 최대 5회), 등록한 뒤에는 바꿀 수 없다.
- 취소·신고 결정 전까지 작업비는 **골목인턴이 그대로 보관**한다.

## 진행 단계

**착수 → 학생의 초안 제출 → 사장님의 수정 요청 및 수정 스킵 → (수정 요청 시) 학생의 최종 수정안 제출 → 최종 완료**

- **착수:** 사장님 결제(예치) 후 학생이 작업을 시작한 상태
- **초안 제출:** 학생이 초안을 제출한 상태. 이때부터 사장님은 취소할 수 없다. 초안 마감일까지 제출할 것.
- **사장님의 수정 요청 및 수정 스킵:** 사장님은 의뢰 등록 때 정한 횟수(최소 1회 · 최대 5회) 안에서 수정을 요청할 수 있고, 학생은 그 요청에 맞춰 수정한다. 단, 사장님이 초안이 마음에 들어 따로 수정 요청이 없을 경우 바로 최종 완료 단계로 넘어간다.
- **수정 요청 시 - 학생의 최종 수정안 제출:** 요청 사항에 맞춰 최종 마감일까지 학생이 최종 수정안을 제출할 것.
- **최종 완료:** 사장님이 완료 확인을 누르거나, 제출 후 7일 동안 응답이 없어 자동 완료된 상태

## 시점별 취소 기준

| 시점 | 취소 방법 | 학생 정산 | 사장님 환불 |
| --- | --- | --- | --- |
| 의뢰 모집 중: 의뢰서를 올린 후 지원자 선택하기 전 | 사장님 단독 가능 (지원한 학생들에게 취소 안내) | 0원 | 전액 |
| 제안 대기 중: 학생이 제안을 보낸 후 사장님 수락 전 | 학생 단독 가능 (제안과 모인 공감이 함께 사라짐) | - | - (결제 전) |
| 작업 시작 전: 사장님이 제안 수락 후 의뢰서 조건이 학생 측에서 맞지 않을 때 | 학생이 취소 | 0원 | 전액 |
| 작업 시작 전: 결제 후 학생이 작업을 시작하기 전 | 사장님 단독 가능 | 0원 | 전액 |
| 작업 중 (초안 제출 전): 제안 - 학생의 의뢰서 수락 후 / 의뢰 - 사장님의 지원자 선택 후 | 사장님 단독 가능 (취소 이유 선택, 학생에게 남길 말 선택 입력) | 착수 보상 (작업비 20%) | 나머지 80% |
| 초안 제출 후 (초안, 최종 수정안 전부) | **취소 불가** | 전액 | - |
| 학생 문제 (연락 두절·노쇼·마감 초과·빈 결과물) | 초안 제출 전, 사장님이 **학생 문제 신고(메일 문의)** → 운영자 판단 | 인정 시 0원(노쇼 기록) / 불인정 시 착수 보상 20% | 인정 시 전액 / 불인정 시 80% |

### 결과물 제출 후

- 사장님은 **수정 요청(의뢰를 처음 등록할 때 정한 횟수, 최소 1회 · 최대 5회)** 또는 **작업 완료 확인** 중 하나를 선택한다.
- 제출 후 **7일** 동안 응답이 없으면 자동으로 완료 처리되고 작업비가 학생에게 정산된다.
- 결과물이 의뢰 내용과 전혀 다르거나 파일이 비어 있는 경우에만 **신고하기**로 운영자가 판단한다.

## 금액 계산

해커톤 버전은 **수수료 없이** 계산한다. 사장님이 예치한 작업비 = 학생 정산금 + 사장님 환불금

**예시:** 작업비 100,000원, 사장님 사정으로 작업 중 취소

- 결제한 금액: 100,000원
- 학생 착수 보상: 20,000원 (작업비의 20%)
- **사장님 환불: 80,000원**

<details>
<summary>실제 런칭 시 적용 (비즈니스 모델 · 수수료)</summary>

- 해커톤 기간에는 적용하지 않고, 런칭할 때 비즈니스 모델로 확정한다.
- 수수료는 학생에게 정산되는 금액 비율만큼만 떼고 나머지는 함께 환불하는 방식을 검토 중
- 예시 (수수료 5% 가정): 결제 105,000원 → 착수 보상 20,000원 + 보상분 수수료 1,000원 → 사장님 환불 84,000원

</details>

## 학생 문제로 취소할 때 (신고 절차)

사장님이 학생 탓으로 돌려 전액 환불을 받는 편법을 막기 위해, 앱에서 바로 환불하지 않고 **메일 문의 → 운영자 판단**으로 처리한다. 앱 안의 별도 소명 절차는 두지 않는다.

1. **사장님 - 학생 문제 신고:** 초안 제출 전에만 가능하다. [학생 문제 신고]를 누르면 **메일 문의 안내 팝업**이 뜬다. 팝업은 골목인턴 운영 메일 주소와 메일에 적을 내용(의뢰 이름, 문제 종류(연락이 안 돼요 / 약속에 안 나왔어요(노쇼) / 마감을 넘겼어요 / 결과물이 비어 있어요 / 기타), 자세한 설명, 증거 자료(채팅 화면·사진 등))을 안내한다.
2. **운영자 - 판단:** 골목인턴 운영자가 메일 내용과 채팅 기록을 보고 결정한다.
3. **결과:** 학생 문제로 인정되면 사장님은 작업비 전액을 돌려받고 학생은 0원·노쇼로 기록된다. 인정되지 않으면 일반 취소 규칙(학생 착수 보상 20%, 사장님 80% 환불)이 적용된다. 결과는 알림과 채팅으로 알린다.
4. **결정 전까지:** 작업비는 골목인턴이 보관한다. 학생이 그사이 결과물을 보내면 사장님은 메일로 신고를 철회하고 작업을 이어갈 수 있다.

## 화면 구성 (사장님)

1. **의뢰 취소 확인 (모집 중·팝업):** 학생을 고르기 전 의뢰 취소. 전액 환불과 지원한 학생들에게 취소 안내가 간다는 안내 → 의뢰 취소 완료 팝업
2. **작업 취소 - 이유·환불 금액:** 취소 이유 선택, 학생에게 남길 말(선택), 작업비·착수 보상 20%·돌려받는 금액 계산, 되돌릴 수 없다는 동의 체크 → 작업 취소 완료 팝업. 이 화면에서 [학생 문제 신고]로 이동할 수 있다.
3. **학생 문제 신고 - 메일 문의 안내 (팝업):** 운영 메일 주소, 메일에 적을 내용(의뢰 이름·문제 종류·설명·증거 자료), 운영자 판단 전까지 작업비는 골목인턴이 보관한다는 안내
4. **취소·환불 안내 (팝업):** 안전결제 전에 보여 주는 시점별 환불 규칙 요약

## 화면 구성 (학생)

1. **의뢰 취소 알림 - 사장님 사정 (팝업):** 사장님 사정으로 취소돼 착수 보상이 정산된다는 안내
2. **제안 취소 확인 (팝업):** 사장님 수락 전 내 제안 취소. 제안과 모인 공감이 함께 사라진다는 안내 → 제안 취소 완료 팝업
